Three homepage concepts for argflex.co.uk

Same content, same catalogue data, three different design directions. Each version is a static HTML page with its own stylesheet, no frameworks, no external fonts and no third-party scripts — so it stays fast when it becomes the PHP front end.

Version 1 — selected

Industrial Precision

Dark navy and orange. Full-bleed photo hero, trust strip, marquee ticker, filterable product grid, industries row, animated counters.

  • Closest to the current brand feel
  • Strong conversion path: hero → categories → products
  • Now includes the ticker from v3 and the industries row from v2

What is inside

  • index.php (v1, now the live homepage), home-v2.html, home-v3.html — the three concepts
  • assets/css/v1.css, v2.css, v3.css — one stylesheet per concept (~8–12 KB each)
  • assets/img/ — logo, hero and 24 product photos pulled from the live site
  • Real catalogue data: 36 products, 12 categories, live prices and blog posts

Performance notes

  • No jQuery, no Bootstrap, no Google Fonts — system font stack only
  • One CSS file and under 40 lines of inline JavaScript per page
  • Every below-the-fold image is loading="lazy"; the hero is preloaded
  • Explicit width/height on images to keep CLS at zero
